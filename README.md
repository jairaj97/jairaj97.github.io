## Edit and publish

The homepage is plain HTML and CSS. Edit `index.html` and `fieldnotes.css`, then push to `main`. GitHub Pages serves the repository root; `.nojekyll` disables Jekyll processing. No build or cross-repository synchronization is required for this site.

The case study records the successful 29 September 2026 release and zero-change Terraform plan. Implementation links are pinned to the verified project revision; the early Docker notes link to a historical revision. Re-check the project implementation before changing those claims.
