## Edit and publish

The homepage is plain HTML and CSS. Edit `index.html` and `fieldnotes.css`, then push to `main`. GitHub Pages serves the repository root; `.nojekyll` disables Jekyll processing. No build or cross-repository synchronization is required for this site.

Source links in the case study are pinned to the reviewed Azure AKS repository revision. Re-check the project implementation before changing those claims or marking planned work as complete.
